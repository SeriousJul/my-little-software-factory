# Getting Started

The control plane ships through npm and installs nothing. Three steps take
you from a blank machine to a working control plane:

1. [Prerequisites](./prerequisites.md) - what the machine needs.
2. [First launch](./first-launch.md) - start it with `npx`.
3. [Minimal config](./minimal-config.md) - the config file, a working
   ticket source, and how to extend the template.
